# Animus 5.2.0

## Changes

### Artwork
- Reworked all sigil textures to match NeoVitae's new sigil style, using a kanji symbol on the shared base sigil

### Spears renamed to Javelins
- All spears are now called javelins in item names, tooltips, and the guide book
- Item and recipe IDs are unchanged, so existing worlds are unaffected

## Bug Fixes

- Fixed the Sentient Bow and Hellforged Bow not firing any projectile
- Fixed javelins not spawning a projectile when thrown
- Fixed the Bound Javelin never binding, which prevented activation and its lightning strike on impact
- Added an activate/deactivate sound to the Bound Javelin
- Fixed missing and incorrect translation keys on the bows, javelins, sigils, and the Ritual of Boundless Skies

## Dependencies

- Modonomicon and GeckoLib are now correctly declared as required dependencies
