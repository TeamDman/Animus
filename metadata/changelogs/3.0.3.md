# Animus 3.0.3

## Bug Fixes

### Ritual Registration Timing
- Fixed ritual registration timing to avoid conflicts with Blood Magic's Patchouli multiblock registration
- Rituals are now registered during ServerStartingEvent instead of mod init

### Dedicated Server Crash
- Fixed `BootstrapMethodError: Attempted to load class LocalPlayer for invalid dist DEDICATED_SERVER`
- Wrapped client-only code (Minecraft class references) in DistExecutor calls in:
  - ItemSigilCrimsonWill (tooltip power calculation)
  - AnimusSigilBase (binding owner name lookup)
  - ItemSigilBuilder (moved right-click delay to client helper class)
  - RitualCodePacket (clipboard access)
  - ItemSentientShield (custom renderer)
  - AltarGhostBlocksPacket (ghost block rendering)
  - ItemSigilEquivalency (shift-down tooltip check)
  - AnimusFluids (fluid type client extensions)
