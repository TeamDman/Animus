# Animus 3.0.2

## Bug Fixes

### Blood Magic Version Compatibility
- Updated Blood Magic dependency from 3.3.2-44 to 3.3.5-47 to match production versions
- Fixed `NoClassDefFoundError` for `ItemSentientScythe` caused by class relocation in newer Blood Magic versions
- Fixed import path for `ItemSentientScythe` (moved from `common.item` to `common.item.soul`)

### Patchouli Book Loading
- Fixed book failing to load when optional compat mods are not installed
- Added mod flags to all compatibility entries so they only appear when the relevant mod is present:
  - Botania entries: `rune_unleashed_nature`, `ritual_floral_supremacy`
  - Ars Nouveau entries: `arcane_rune`, `living_armor_ars_nouveau`
  - Iron's Spellbooks entries: `blood_infused_spellbook`, `living_armor_spells`, `ritual_arcane_mastery`, `sanguine_scrolls`, `sigil_crimson_will`
  - Malum entries: `runic_sentient_scythe`, `hand_of_death`

## New Content

### Patchouli Documentation
- Added new book entries for Malum compatibility items:
  - **Runic Sentient Scythe** - Documentation for the enhanced sentient scythe with Malum soul harvesting
  - **Hand of Death** - Documentation for the ultimate soul-reaping weapon with lifesteal and execute mechanics

## Technical Changes
- Ritual registration now uses reflection-based registration for compat rituals to avoid class loading issues with optional mods
- Added UUID constants for item attribute modifiers
