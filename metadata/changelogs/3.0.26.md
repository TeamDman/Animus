# Animus 3.0.26

## Changes

### Bug Fixes

- **Fixed Tier 6 Ascension advancement firing on every block placement**: The `tier6_ascension` advancement used a malformed `minecraft:placed_block` criterion (a `location` array wrapping a `block_state_property` condition) that the vanilla deserializer treated as no-conditions, so the achievement was awarded whenever the player placed any block. Replaced the criterion with a clean `placed_block` check on `animus:crystallized_demon_will_block` so the advancement only fires when the player actually places a Tier 6 capstone, matching the advancement's description.
