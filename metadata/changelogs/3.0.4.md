# Animus 3.0.4

## Bug Fixes

### Dedicated Server Rendering
- Fixed Sigil of Temporal Dominance acceleration overlay not rendering when playing on a dedicated server
- Added network synchronization to send acceleration data from server to client
- This also fixes the Ritual of Floral Supremacy acceleration display

### Sigil of Holding Compatibility
- Fixed Sigil of Phantom Chains not working when placed inside a Sigil of Holding
- Now uses raycasting to detect target entity, compatible with how Sigil of Holding forwards interactions

## New Features

### Blood Apple LP Redirection
- When eating a Blood Apple with a bound Key of Binding in your inventory or Curios slot, LP is now deposited into the key owner's soul network instead of your own
- Works with keys in main inventory, offhand, or equipped Curios slots
- Allows players to "farm" LP for other players

### Code Cleanup
- Replaced inline fully qualified class names with proper imports throughout the codebase
- depulicated some client side code
- added some guarding vs missing addons breaking the patchouli book
