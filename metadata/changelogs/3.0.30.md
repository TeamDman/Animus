# Animus 3.0.30

## Changes

### Bug Fixes

- **Ritual of Peaceful Beckoning no longer summons blacklisted mobs**: The ritual now skips any entity in the `animus:disallow_capturing` tag when building its spawn pool. Previously it only filtered by mob category, which let miscategorized "peaceful" mobs (dragons, bosses, and other out-of-place modded creatures) slip into the pool. Tagged mobs can no longer be beckoned.
