# Animus 3.0.29

## Changes

### Bug Fixes

- **Fixed spellcasting Living Armor upgrades never leveling up**: The Arcane Channeling (Iron's Spells) and Source Attunement (Ars Nouveau) upgrades had all of their level thresholds set to 0 XP, which collapsed their progression and prevented casting spells from ever granting a level. They now use ascending XP requirements and level up properly as you cast.
