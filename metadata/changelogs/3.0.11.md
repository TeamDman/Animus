# Animus 3.0.11 Changelog

## New Features

### Botania Integration

- **Wand of the Forest HUD Support**: Diabolical Fungi and Rune of Unleashed Nature now display mana information when looking at them while holding Botania's Wand of the Forest
  - Diabolical Fungi shows current mana buffer with dark red theme
  - Rune of Unleashed Nature shows mana level and active state with indigo theme

### Ars Nouveau Integration

- **Dominion Wand Tooltip**: Arcane Rune now displays source information when looking at it with Ars Nouveau's Dominion Wand
  - Shows source level as percentage (e.g., "Source: 50% (500/1000)")
  - Displays powered/unpowered state with color-coded status

## Bug Fixes

### Botania Integration

- Fixed Rune of Unleashed Nature not syncing mana data to clients, causing Wand HUD to show empty

### Blood-Infused Spellbook (Iron's Spells Integration)

- Fixed LP casting not working - spellbook now properly consumes LP when mana is insufficient
- LP cost reduction now applies based on spellbook tier:
  - Tier 4: 10% LP cost reduction
  - Tier 5-6: 20% LP cost reduction

### General

- Mixed mineable tags not being set correctly for runes
