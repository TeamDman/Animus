# Animus 3.0.12 Changelog

## New Features

### Ritual Tinkerer Support

Added Ritual Tinkerer support for 8 additional rituals that previously had fixed ranges:

- **Ritual of Endless Greed**: Effect range and chest location now modifiable
- **Ritual of Nolite Ignem**: Fire suppression radius now modifiable
- **Ritual of Peaceful Beckoning**: Spawn area now modifiable
- **Ritual of Persistence**: Chunk loading area now modifiable
- **Ritual of Relentless Tides**: Fluid placement area and tank location now modifiable
- **Ritual of Serenity**: Mob spawn prevention radius now modifiable
- **Ritual of Siphon**: Fluid extraction area and tank location now modifiable
- **Ritual of Floral Supremacy**: Flower supercharge radius now modifiable

## Bug Fixes

### Block Drops

- **Rune of Unleashed Nature**: Fixed not dropping when broken in survival mode
- **Arcane Rune**: Fixed not dropping when broken in survival mode
- **Diabolical Fungi**: Fixed not dropping when broken in survival mode
- Added proper loot tables for all compat blocks (Botania and Ars Nouveau integration blocks)

### Willful Stone

- Fixed Willful Stone not being breakable by the player who placed it in survival mode
- The block now properly uses `getDestroyProgress()` to check ownership before allowing breaking

### Iron's Spells Integration

- **Blood-Infused Spellbook LP Casting**: Fixed LP not being used when mana is low
  - Rewrote LP casting system to intercept spells BEFORE mana validation
  - Uses `SpellPreCastEvent` to add temporary mana, then consumes LP in `SpellOnCastEvent`
  - Previously the handler fired after mana validation, causing "not enough mana" error
  - Now properly checks main hand, offhand, curios slots, and inventory for the spellbook

### Rituals

- **Ritual of Nature's Leech**: Fixed radius modification not working with Ritual Tinkerer
  - Added missing localization keys for range info display (was showing raw translation key)
  - Corrected `setMaximumVolumeAndDistanceOfRange()` parameters (first param should be 0 for unlimited volume)
  - Fixed range calculation to properly create symmetric effect area

- **All Rituals with Modifiable Ranges**: Added missing `.info` localization keys
  - Ritual of Culling (altar, effect)
  - Ritual of Entropy (chest)
  - Ritual of Luna (effect, chest)
  - Ritual of Reparare (chest)
  - Ritual of Sol (effect, chest)
  - Ritual of the Steadfast Heart (effect)
  - Ritual of Unmaking (effect)

### Botania Integration

- **Ritual of Floral Supremacy**: Refactored to properly isolate Botania-specific code
  - Created FloralSupremacyHelper class to handle Botania API calls
  - Prevents class loading issues when Botania is not present
