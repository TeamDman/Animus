# Animus 4.0.1

## Blood Magic Compatibility
- Updated to Blood Magic 3.4.0-3-beta
- Updated mod dependency from `bloodmagic` to `bloodmagicnv`

## Iron's Spells Integration
- Blood-Infused Spellbook now uses data-driven Blood Altar recipes
- Initial spellbook infusion preserves all equipped spells via `copyInputComponents`
- Supports all 6 Iron's Spells spellbook types (leather, copper, iron, gold, diamond, netherite)
- Updated Patchouli documentation for new altar-based crafting
- Updated tooltip for tier 0 spellbooks

## Ars Nouveau Integration
- Re-enabled Ars Nouveau compatibility module
- Added proper class loading isolation to prevent crashes when Ars Nouveau is not installed

## Bug Fixes
- Fixed crash when Iron's Spells is not installed
  - Changed method references to lambdas in DeferredHolder registrations
  - Added IronsSpellsCompatLoader class to isolate optional dependency references
- Fixed potential crash when Ars Nouveau is not installed
  - Added ArsNouveauCompatLoader class for proper class loading isolation
  - Changed method references to lambdas in ArsNouveauCompat

## Technical Changes
- Improved compat module loading pattern to prevent NoClassDefFoundError
- All compat modules now use loader classes to isolate optional dependency references
