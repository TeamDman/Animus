# Animus 3.0.22

## Changes

### Bug Fixes

- **Fixed Iron Spear AOE**: Iron spears no longer deal AOE damage on impact. AOE is now exclusive to diamond and bound spear variants.
- **Fixed Reduction ritual JEI description**: Corrected the JEI info text to show Quartz Block instead of Bookshelf as the trigger block.
- **Fixed diamond spear tooltip**: Updated tooltip to mention AOE damage on impact.

### Enhancement Ritual Redesign (Dynamic Enchantment Boosting)

The Imperfect Ritual of Enhancement has been completely redesigned to prevent an exploit where boosted enchantment levels could be extracted via grindstone or disenchanting and then re-applied indefinitely.

- The ritual now marks the item as **Blood Enhanced** without modifying actual enchantment data
- A +1 level boost is applied **dynamically** at query time via Mixin (`EnchantmentHelperMixin`), affecting both individual level checks and aggregate calculations
- Tooltip displays a purple "Blood Enhanced (+1)" indicator via `EnhancementTooltipHandler`
- Stripping enchantments (grindstone, disenchanting) yields only the **base** enchantment levels
- The Blood Enhanced mark persists on the item and will boost any new enchantments applied to it

### Reduction Ritual Simplified

- Now only removes the Blood Enhanced mark from an item
- No longer downgrades enchantment levels - enchantments simply return to their base values
- Only works on items that have the Blood Enhanced mark

### Unmaking Ritual Updated

- No longer skips Blood Enhanced items - they can be processed normally
- Extracted enchantment books contain base (unboosted) levels
- Removed the `unmakingDisallowEnhanced` config check

### JEI Imperfect Ritual Displays Now Data-Driven

- JEI imperfect ritual displays are now derived from loaded recipe data instead of being hardcoded
- This prevents display/recipe desync bugs (like the Reduction trigger block mismatch)
- Catalyst blocks are also registered dynamically from recipe data

### Admin Commands (`/animus`)

Added a full `/animus` command tree for server operators (permission level 2+):

- `/animus getlp` - Display current Soul Network LP
- `/animus setlp <amount>` - Set Soul Network LP
- `/animus fillwill <type>` - Fill current chunk with demon will (supports all 5 types)
- `/animus gemtype <type>` - Change demon will type of held tartaric gem
- `/animus fillgem` - Fill held tartaric gem to max capacity

### Other

- Enabled Access Transformers in build.gradle
- Removed Blood Apple crafting recipe
- Added Patchouli guide entries for admin commands
- Updated Patchouli guide entries for Enhancement, Reduction, and Unmaking rituals
