# Animus 4.0.2

## Bug Fixes (Ported from 1.20.1)

### Ritual Tinkerer Support
- Fixed Ritual of Sol not respecting Ritual Tinkerer range modifications
  - Now correctly derives search bounds from the AreaDescriptor AABB
- Fixed Ritual of Luna not respecting Ritual Tinkerer range modifications
  - Now correctly derives search bounds from the AreaDescriptor AABB

### Crash Fixes
- Fixed potential crash when dying while AntiLife blocks are spreading
  - Added `player.isAlive()` check before attempting LP consumption
  - Protection checks now skip gracefully when player is dead or offline
- Fixed potential NPE in block break events when player is null
  - Added defensive null check to MonkSigilEventHandler.onBlockBreak

### Iron's Spells Integration
- Fixed Crimson Will spell power buff remaining permanently applied if casting was cancelled or sigil was toggled off mid-cast
  - Added player tracking for modifier cleanup
  - Added tick-based cleanup handler for cancelled spell casts
- Fixed LP casting not working when player has insufficient mana
  - Added mixin-based approach that injects temporary mana before the mana check runs
  - This allows LP casting to work properly in all cases

### Sigil Fixes
- Fixed Demon Monk Sigil applying its damage bonus to spell damage
  - Monk bonus now only applies to direct melee attacks (player is the direct damage entity)
  - This prevents spells from Iron's Spells from triggering monk damage bonuses

### Item Fixes
- Fixed crash when Sentient Shield had a stored demon will type with different casing
  - Enum parsing now correctly handles case-insensitive values (e.g., "default" vs "DEFAULT")
